01 · THE PROBLEM

Continuous listening should not mean continuous cloud processing.

VAANI addresses the engineering gap between always-on voice activation and resource-constrained edge hardware.

Continuous Listening

The edge device inspects incoming audio continuously without requiring a full remote speech stack to run all the time.

False Activation

Incorrect wake events can trigger unnecessary recording, network transmission and speech-recognition processing.

Low Latency

The system measures the path from keyword ending to local detection, stream start and first remote packet.

Core requirement: keep the wake decision local; open the network speech path only after a valid custom wake event.

LOCAL PATH

Microphone → DSP → TinyML KWS → confidence decision. This path operates continuously on the edge device.

NETWORK PATH

Wake → pre-roll → audio streaming → remote ASR → application. This path activates only after a valid wake event.

EDGE GATE
