ARCHITECTURE
Local intelligence first.
VAANI continuously processes microphone audio locally on the edge device using lightweight keyword spotting.

The wake word is detected locally using MFCC / Log-Mel features and a lightweight INT8 neural network.

Only after the wake event does VAANI optionally activate Wi-Fi and stream subsequent audio toward remote ASR.

This architecture minimizes unnecessary network traffic, reduces privacy exposure, and targets low-latency voice activation.
